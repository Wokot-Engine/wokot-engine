# It's a free and open source game engine for everyone

Wokot Engine was created with the core idea that game development should be there for everybody.

Wokot Engine is a community-driven game engine which was forked from Godot to remove bigotry. Therefore Wokot combines a high-performance game engine with a welcoming environment for creators across the globe.

# 💡 Why Wokot?

While other forks claim neutrality where they actually welcomed bigotry under the false flag of harassment, Wokot Engine takes a clear stand:

- **Welcome for everyone**: Everyone belongs here and is allowed to participate, no matter whether you write your first line of code or work on a professional game title.

- **Zero tolerance against hate speech**: Creativity requires to be safe from gatekeeping. The community spaces are actively moderated to disallow harassment and bigotry.

- **100% Free and Open Source**: Licensed under the MIT license, your games belong entirely to you.

- **Built on established technology**: Powered by the Godot Engine, you have access to 2D and 3D rendering, and the GDScript programming language.

# Getting the engine
## Binary downloads

Official binaries for the Wokot editor and the export templates are not available but you can compile the game engine from source.

``` bash
git clone https://github.com/Wokot-Engine/wokot-engine.git
cd wokot-engine
scons
```
